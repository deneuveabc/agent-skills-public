# 播客音频剪辑

用于处理单期播客的原始音频。先读用户提供的本期要求；若工作区有私有剪辑标准，也先读取并以其为准。节目名称、主持人、嘉宾、开头和结尾标志、删减范围、文风与输出位置均按本期材料确定，不在公开 Skill 中预设。

## 开始前

1. 确认原音频、逐字稿或词级时间戳、目标输出格式和目录。缺少词级时间戳时仍可先做结构剪和停顿压缩。
2. 用 `ffprobe` 检查时长与编码，试听首尾和拟删段落。结构删减属于内容判断，列出时间范围及理由供用户确认后再剪。
3. 确认本机有 `ffmpeg`、`ffprobe` 和 Python 3。需要自动去口癖时，准备与原音频对齐的 SenseVoice 词级 JSONL；转写工具与模型由本地环境提供，仓库不包含它们。

## 1. 粗剪与精剪

`scripts/build_cuts.py` 按原音频时间处理结构删减、长停顿和可选口癖。先输出可听的粗剪版，取得反馈后再精剪。

```bash
python3 scripts/build_cuts.py \
  --audio input.m4a --output rough-cut.m4a \
  --cut "0,12.0" --cut "180,205" \
  --segments-out kept-segments.txt
```

- `--cut "start,end"` 删除一个原音频区间；`END` 代表结尾。时间数值仅为用法示例，实际剪点必须根据本期音频确定。
- 默认将超过 2 秒的静音缩至 0.7 秒，可用 `--min-gap`、`--keep-gap` 调整。
- 提供 `--sensevoice words.jsonl` 后会按脚本内的词表去口癖；`--no-filler` 可关闭。词表可能误删有语义的“就是”“然后”等词，交付前要试听。
- `--segments-out` 保存原音频中最终保留的时间区间，供章节映射使用。

转写若需预处理，可将音频转为单声道 16 kHz WAV，再运行本机已安装的转写工具；具体命令和模型路径以当前环境为准。

## 2. 降噪与响度

```bash
bash scripts/loudness_master.sh rough-cut.m4a final.m4a
```

脚本用 `afftdn` 降噪，并以两遍 `loudnorm` 将成片处理至 -16 LUFS、真峰值 -1.5 dB、LRA 11。降噪强度需按源噪声试听调整；脚本中的 `NR=10` 是初始值。脚本输出 AAC 192k、32 kHz 音频。

## 3. 章节时间轴与文案

章节时间应对应成片，而非原音频。用 `kept-segments.txt` 映射本期确认的原音频章节点：

```bash
python3 scripts/map_chapters.py kept-segments.txt "226|章节一" "710|章节二"
```

按本期写作要求制作 shownote；发布前核对嘉宾、工具和其他专有名称。不要把音频、逐字稿、shownote、账号信息或本机路径提交到公开 Skill 仓库。

## 验收与限制

- 试听所有结构剪接点、口癖处理点及首尾；硬切可能产生点击声或语气过赶，必要时在音频编辑器中修复。
- 用 `ffprobe` 检查输出时长，并回听响度、噪声和明显静音断层。脚本输出不等于人工听审通过。
- 记录本期使用的删减区间、参数、输出文件及已知问题，保存在本期私有项目目录。
