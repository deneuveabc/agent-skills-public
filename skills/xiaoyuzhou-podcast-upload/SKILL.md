# 小宇宙播客内容上传

处理用户指定播客工作区中的单集。用户未给路径时，优先检查当前工作区的 `Podcast` 子目录或本次会话已明确给出的播客根目录；若都无法定位，询问用户。使用当前 Agent 可用的文件工具和小宇宙创作者中心操作；本 Skill 不依赖某个 Agent 专有命令、浏览器接口或固定页面控件。

## 定位本次单集

1. 用户给出具体文件夹或文件路径时，以该路径为准。否则查看播客根目录下近期有实际单集内容的子文件夹（必要时也查看根目录的散文件），结合日期、标题和最近修改的**内容文件**选候选；不要把最新修改时间或 `.DS_Store` 当作唯一依据。多个候选无法确定时，列出候选并请用户指定。
2. 读取候选文件夹中适用的 `AGENTS.md` / `CLAUDE.md`、上传信息卡、shownote、剪辑记录等。名称可能不同，按内容判断。区分原始录音、粗剪、精剪与定版；以用户本次指定和文件中的最终版本说明为准。只有文件名含“终”“定版”并不足以在冲突时决定版本。
3. 核对最终音频确实存在、格式和大小可上传、时长与 shownote 时间轴相符。可用本地音频元数据工具核实；若时间轴属于旧剪辑版、音频损坏、缺少 shownote 或标题不明确，先解决对应问题，不猜补内容。

## 准备并上传

1. 从本次文件夹提取节目、单集标题、简介、时间轴及已确认的封面或其他设置。上传信息卡可作操作摘要；如它与较新的定稿冲突，回原文件和剪辑记录核实。保留用户原有表述，不把旧单集的标题、嘉宾、分类、封面或发布日期套用到新一期。
2. 进入小宇宙创作者中心 `https://podcaster.xiaoyuzhoufm.com/`，确认登录账号和目标节目。先查单集列表，避免重复创建。未登录时请用户完成必要的扫码、验证码或其他本人操作，再继续。
3. 按页面当前入口创建单集，上传**已核对的最终音频**，填写标题与完整 shownote。若编辑器支持时点，检查粘贴的时间戳是否被识别；否则按平台现有方式录入。封面、定时发布、分类、创作声明等仅按本次素材与用户指示设置，不凭上期配置推断。
4. 保持上传页面打开，直到后台明确显示音频上传完成及正确时长；提交前复核标题、正文、时间点、音频文件和发布设置。用户本次要求上传或发布才授权相应外部操作；本 Skill 本身不构成授权。涉及平台服务协议等有法律约束力的接受动作，按当前环境规则在动作当时取得用户确认。

## 核验结果

提交后打开后台生成的单集页面，核对音频与 shownote 已保存，记录单集链接及后台状态。准确区分“上传中”“已创建／转码中”“审核中”和“已公开上线”；仅见到后台页面或提交按钮反应不算公开发布成功。若上传、提交或审核失败，说明具体状态并继续处理可恢复的问题；避免盲目重复创建单集。
